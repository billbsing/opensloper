# Icons

These icons are from [Tabler Icons](https://tabler.io/icons) 3.50.0, outline style, under the MIT licence in `LICENSE`. They are used unchanged; the app replaces `currentColor` with the theme's text colour when it draws them.

`Sloper.UI.IconSet` lists which file each command uses. To change an icon, copy another outline SVG from the same release here and update that list.
