# Add measurements

## From the catalogue

The catalogue lists the standard body measurements: heights and lengths,
circumferences, widths, arm, leg, crotch, head, hand and foot. Choose a group
or type in the search box, pick a measurement, and click **Add to the file**.

While a catalogue entry is picked, the body figure shows where it is taken,
with how to take it and its usual range underneath. Measurements already in
the file are left out of the list, so a file holds only the ones its person
needs.

An added measurement takes the catalogue's description. In one person's set it
starts at 0, which the range warning points out until you type the value; in a
size table it starts with no values.

## Your own measurements

For anything the catalogue does not have, click **Add** under the table. A new
row appears with its key ready to type: follow the key rules (letters, digits
and underscore, not starting with a digit), then fill in the value and a
description.

Product sizes work the same way. A bag pattern can read `@width`, `@height` and
`@depth` from a file of its own; nothing in a measurement file has to be a
body measurement.

## Order and removal

**Up** and **Down** move the selected measurement in the list; patterns do not
care about the order. **Delete** removes it, after asking, since patterns that
use it will show it as missing.
