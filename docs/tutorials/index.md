# Tutorials

Worked projects from start to finish. Each one has its finished pattern, so you
can open it and compare.

- [A straight skirt block](skirt-block.md): the basics of drafting by formula,
  from measurements to two pieces ready to print.
- [A bodice block](bodice-block.md): a close-fitting block with darts,
  armholes, seams checked for length, and notes.

For finished patterns without the steps, see
[Example patterns](../getting-started/examples.md).
