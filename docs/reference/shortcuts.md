# Keyboard shortcuts

!!! note

    This page is generated from the program by `opensloper-cli doc shortcuts`; do not edit it by hand.

On macOS, Cmd takes the place of Ctrl. Keys on the canvas work while the canvas has the focus: click it first if you were typing in a panel.

## Design app

### File

| Keys | What it does |
| --- | --- |
| ++ctrl+n++ | New file |
| ++ctrl+o++ | Open a file |
| ++ctrl+s++ | Save |
| ++ctrl+shift+s++ | Save under another name |
| ++ctrl+m++ | Open a measurement set for the pattern |
| ++ctrl+p++ | Lay out and print the pattern in the publish app |
| ++ctrl+q++ | Quit |

### Edit

| Keys | What it does |
| --- | --- |
| ++ctrl+z++ | Undo |
| ++ctrl+shift+z++ | Redo |
| ++ctrl+x++ | Cut the selection, or text in a field |
| ++ctrl+c++ | Copy the selection, or text in a field |
| ++ctrl+v++ | Paste |
| ++ctrl+comma++ | Preferences |

### View

| Keys | What it does |
| --- | --- |
| ++ctrl+plus++ | Zoom in |
| ++ctrl+minus++ | Zoom out |
| ++ctrl+0++ | Fit everything in the window |
| ++ctrl+1++ | Show the pattern at its true size |
| ++ctrl+r++ | Show or hide the rulers |

### Tools

| Keys | What it does |
| --- | --- |
| ++s++ | Select tool |
| ++z++ | Zoom tool |
| ++p++ | Point tool |
| ++l++ | Line tool |
| ++c++ | Curve tool |
| ++o++ | Circle tool |
| ++r++ | Rectangle tool |
| ++k++ | Piece tool |
| ++t++ | Notch tool |
| ++e++ | Seam tool |
| ++x++ | Text tool |
| ++a++ | Callout tool |

### On the canvas

| Keys | What it does |
| --- | --- |
| ++escape++ | Cancel a drag or what the tool is doing; then go back to the Select tool; then clear the selection |
| ++delete++ | Delete the selection; Backspace does the same |
| The arrow keys | Move the selected points 1 mm |
| ++shift++ and the arrow keys | Move the selected points 10 mm |
| ++n++ | Show every label while held |
| ++tab++ | Seam tool: go on to the other side of the seam |
| ++shift+tab++ | Seam tool: go back to the first side |
| ++enter++ | Seam tool: make the seam |

### In the tables

| Keys | What it does |
| --- | --- |
| ++f2++ | Edit the cell, or start typing |
| ++enter++ | Keep the change to the cell |
| ++escape++ | Put the cell back as it was |

### Mouse

| Keys | What it does |
| --- | --- |
| The wheel | Scroll up and down |
| ++shift++ and the wheel | Scroll sideways |
| ++ctrl++ and the wheel | Zoom about the pointer |
| Drag with the middle button | Pan |
| ++space++ and drag | Pan |
| ++alt++ and click | Select the next of several lines in the same place; clicking again at the same spot does the same |
| ++shift++ and click | With the Curve tool, carry the last curve on through the point, as one curve path |
| Right-click | With the Select tool, list everything under the pointer, to pick one; with a drawing tool, stop the line or curve |
